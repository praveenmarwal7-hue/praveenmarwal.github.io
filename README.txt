## Free publishing with GitHub Pages
1. Create/sign in to GitHub.
2. Create a new public repository named `praveenmarwal.github.io` (replace with your GitHub username).
3. Upload `index.html` and `style.css`.
4. Go to Settings → Pages.
5. Under Build and deployment, choose `Deploy from a branch`.
6. Select `main` and `/ (root)`, then Save.
7. Your website will be available at `https://YOUR-USERNAME.github.io/`.

No paid hosting is required.
